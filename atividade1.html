O QUE É UMA REGRA CSS?

Uma regra CSS é um bloco de código utilizado para estilizar elementos em uma página HTML. Ela é composta por duas partes principais: um seletor (que aponta para o elemento HTML que você deseja estilizar) e um bloco de declaração (que define como o elemento deve ser estilizado)

O bloco de declaração fica entre chaves ({}) e contém uma ou mais propriedades seguidas por seus respectivos valores, separados por dois-pontos (:) e finalizados por ponto e vírgula (;).

EXEMPLO DE REGRA CSS:

h1 { color: blue; font-size: 24px; text-align: center; }

p { color: gray; font-size: 16px; }
