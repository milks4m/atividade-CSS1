INCLUINDO CSS EM DOCUMENTOS HTML

CSS externo

Como funciona: O código CSS fica guardado num ficheiro separado com a extensão .css e é ligado ao documento HTML através da tag link no cabeçalho.
Vantagem: É a forma mmais recomendada para projetos reais, pois permite estilizar múltiplas páginas HTML usando apenas um ficheiro de estilos, facilitando a manutenção.

CSS interno

Como funciona: As regras CSS são colocadas diretamente no documento HTML dentro da tag style no cabeçalho da página.
Vantagem: Útil quando uma única página HTML tem regras de estilo únicas que não precisam de ser partilhadas com outros ficheiros.

CSS inline

Como funciona: Os estilos são aplicados diretamente no elemento HTML específico utilizando o atributo style.
Vantagem/Desvantagem: Aplica-se apenas a esse elemento isolado. É geralmente desaconselhado para grandes projetos porque mistura a estrutura (HTML) com o design (CSS), dificultando a manutenção.
